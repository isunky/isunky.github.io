# Sunky WordPress 主题

本目录提供独立的主题包和内容管理插件：

| 安装包 | 内容 |
| --- | --- |
| `dist/sunky-studio.zip` | 作品首页、作品详情、文章列表、文章正文和移动端样式 |
| `dist/sunky-content.zip` | 后台作品、版本记录与下载地址字段 |

安装包位于本目录的 `dist/` 文件夹。前台使用 PHP 模板和 CSS，文章正文继续用 WordPress 区块编辑器。所有公开导航只保留「作品」和「文章」。版本记录出现在对应作品详情页中。

## 安装

1. 在主机上安装 WordPress（6.6 或更新版本），确认 PHP 为 8.0 或更新版本，并把站点地址设为 `https://www.sunky.net`。
2. 在 **插件 → 安装插件 → 上传插件** 上传并启用 `sunky-content.zip`。
3. 在 **外观 → 主题 → 添加主题 → 上传主题** 上传并启用 `sunky-studio.zip`。
4. 在 **页面 → 新建页面** 建立“首页”和“文章”两个页面；“文章”页面的固定链接设为 `articles`。
5. 在 **设置 → 阅读** 选择静态首页，把“首页”设为首页、“文章”页设为文章页。主题会自动使用首页和文章列表模板。
6. 在 **设置 → 固定链接** 选择你喜欢的地址格式并保存一次。

作品首页是主题首页模板，不需要手工插入区块。文章列表自动使用最新发布内容。

## 后台内容

- 在 **作品 → 添加作品** 填写作品名、摘要（一句话简介）、当前版本、作品亮点、主要功能、源码地址和下载地址。特色图片会同时用于首页卡片和作品详情页；没有设置时，八个现有作品会使用主题内的独立插画。版本字段未填写时，首页会显示「版本 —」。
- 后台的作品列表会显示当前版本和状态，版本记录列表会显示所属作品和版本号，方便同时维护多个作品。
- 发布 Windows MSI、便携 ZIP 或 Edge 扩展时，填写对应下载栏。作品页面会自动显示已填写的下载入口；安装包可上传到网站根目录下的下载目录（例如 `public_html/downloads/`），再粘贴 HTTPS 地址。
- 在 **版本记录 → 发布新版本** 选择所属作品，填写版本号、平台、下载地址和更新说明。版本记录显示在对应作品详情页内。
- 在 **文章 → 写文章** 使用区块编辑器撰写并发布文章。特色图片会用于文章页头图；没有设置时会用主题中的文档插画作为默认头图。

## 页面和模板

- 首页列出全部已发布作品，卡片链接到各自详情页，下方显示最新文章。
- 作品详情页包含版本、简介、功能、下载方式和版本记录。没有填写下载链接时不会显示下载按钮。
- 作品详情链接使用 `/works/作品名称/`；启用插件后若链接尚未生效，请在 **设置 → 固定链接** 保存一次。
- 文章列表先突出最新文章，随后列出其他文章；文章正文页面使用易读的窄版式。
- 模板代码负责整体版式，文章正文和作品内容在后台编辑。可在主题 CSS 中更改配色与布局。

## 软件文件

安装包直接放在虚拟主机，后台填写文件链接。若控制面板上传大小不够，可用主机提供的 FTP/SFTP 上传。单文件上限由 PHP 的 `upload_max_filesize`、`post_max_size` 与主机资源配置决定；下载也会占用套餐流量。

主题内置配图已压缩为 WebP，减少主题安装包大小及首页图片流量。如果主机仍限制主题 ZIP 上传，可以通过 FTP/SFTP 将解压后的 `sunky-studio` 文件夹放入 `wp-content/themes/`。

## 本地静态预览

- `wp-content/themes/sunky-studio/preview.html`：作品首页
- `wp-content/themes/sunky-studio/preview-mdview.html`：MDView 作品详情页
- `wp-content/themes/sunky-studio/preview-articles.html`：文章列表页

这些预览使用示例内容，主题安装后由 WordPress 后台内容替换。
